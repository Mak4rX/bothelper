# ⚡ CyberHelper — веб-інструмент касира комп'ютерного клубу

Одна сторінка на чистому JS + невеликий FastAPI-бекенд для тарифів.
**Власної бази даних немає:** звіти змін, акції та каса зберігаються в `localStorage`
браузера, тому застосунок працює на Vercel без диска і не втрачає дані при рестарті сервера.

> Дані живуть в одному браузері й між пристроями **не синхронізуються**. Якщо очистити
> дані сайту в браузері — історія звітів зникне. Текст звіту копіюється в месенджер при створенні.

## Функції

- 💼 **Закриття зміни** — розрахунок каси, заробітку, витрат, інкасації; історія звітів.
- ⭐ **Відгуки** — перевірка телефону/логіна за базою Google Відгуків (пошук у браузері).
- 🎁 **Акції** — перегляд і локальне редагування акцій + таблиця «Тарифи на сьогодні».
- 🧮 **Калькулятор годин** — сума ↔ години за тарифами зон, знижка/кешбек, «Тарифи зараз».
- 💵 **Рахунок каси** — підрахунок готівки за номіналами.
- 💱 **Решта** — розмін суми на купюри, наявні в касі.
- 📝 **Генерація звіту** — текст звіту зміни для адміністраторів.

### Закриття зміни

Розрахунок виконується в браузері (`webapp/static/report.js`), цілими копійками:

- **Зароблено** = кінцева каса − початкова + витрати + інкасація
- **Надлишок** = зароблено − сенет (плюс — надлишок, мінус — недостача)

```
Закриття зміни.
Каса готівки вечері: 7 791
Зароблено за ніч готівки: 886
Торгівельні витрати: 0
Каса готівки зранку: 8 677
3 грн надлишку.
```

Початкова каса наступної зміни підставляється з кінцевої каси останнього звіту.
В історії зберігається до 100 останніх звітів.

### Тарифи

Єдине джерело правди — `pricing.py`; калькулятор і «Тарифи зараз» рахують за одними правилами
(це перевіряє `tests/test_pricing.py`). Час — за Києвом.

| Що | Умови |
|---|---|
| 🌅 Ранок | **Пн–Чт 09:00–15:00** |
| 🎒 Школяр (до 16 р., лише GAMER) | Пн–Чт 130 ₴ до 17:00 · Пт 180 ₴ до 17:00 · Сб–Нд і свята 180 ₴ до 15:00 |
| 🌙 Ніч 10 год | щодня 22:00–08:00 |

П'ятниця — «вихідний» тариф, але Школяр у ній діє до 17:00, тому калькулятор отримує
день тижня (`dow`). Свята касир вибирає вручну в полі «Тип дня».

### Решта

Обидва поля приймають арифметичний вираз: `50+100`, `3*70`, `2*80+50`. Результат
перераховується на кожен символ. Рахує цілими копійками, видає мінімальну кількість купюр,
парсер власний, без `eval()`. Логіка — `webapp/static/change.js`.

## Запуск

```bash
pip install -r requirements.txt
uvicorn webapp.main:app --port 8000
```

Відкрити http://localhost:8000. Swagger UI — http://localhost:8000/docs.

## Структура

| Файл | Призначення |
|---|---|
| `webapp/main.py` | FastAPI: сторінка, тарифи, калькулятор, база відгуків |
| `pricing.py` | Тарифи і правила: Ранок, Школяр, Ніч, пакети |
| `reviews.py` | Завантаження Google Таблиці з відгуками (кеш 60 с) |
| `webapp/static/index.html` | Весь інтерфейс (HTML + CSS + JS) |
| `webapp/static/report.js` | Формули і текст звіту «Закриття зміни» |
| `webapp/static/change.js` | Калькулятор решти |
| `webapp/static/cash-register.js` | Підрахунок каси за номіналами |
| `public/` | Копія фронтенду для Vercel (див. нижче) |
| `api/index.py`, `vercel.json` | Точка входу для Vercel |
| `Dockerfile`, `Procfile`, `fly.toml`, `render.yaml` | Інші платформи |

### Vercel і `public/`

Vercel віддає `public/` напряму, а `/api/*` — через `api/index.py`. Тому фронтенд лежить у двох
місцях: `webapp/static/` (джерело) і `public/`. **Після змін у `webapp/static/` скопіюйте файли:**

```bash
cp webapp/static/index.html public/index.html
cp webapp/static/{change,cash-register,report}.js public/static/
```

`tests/test_static_sync.py` падає, якщо копії розійшлися.

## API

| Метод | Шлях | Що повертає |
|---|---|---|
| GET | `/api/zones` | Зони з цінами |
| GET | `/api/pricing/live?hour=&dow=` | Актуальні тарифи й пакети |
| GET | `/api/calculator/money-to-hours` | `amount, zone, day_type[, current_hour, dow, discount]` |
| GET | `/api/calculator/hours-to-money` | `hours, zone, day_type[, current_hour, dow, discount]` |
| GET | `/api/reviews/database?refresh=` | Контакти з Google Таблиці |

Звіти, інкасації та акції — лише на клієнті, серверних ендпоінтів для них немає.

## Тести

```bash
node --test "tests/*.test.mjs"      # звіт зміни, решта, каса (без залежностей)
pip install pytest httpx
pytest tests                        # тарифи, відгуки, синхронність public/
```

E2E-перевірка вкладки «Решта» у браузері (Playwright), спершу підніміть сервер:

```bash
pip install playwright && playwright install chromium
python tests/e2e_change.py http://127.0.0.1:8000
```

## Безпека

Сервер не зберігає дані і не має мутуючих ендпоінтів — лише читання тарифів і таблиці відгуків.
Кнопка «Режим адміністратора» в «Акціях» — не авторизація, а лише зручність: акції й так
зберігаються локально в браузері кожного касира.
